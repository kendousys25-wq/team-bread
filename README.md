## 開発ルール

- mainに直接pushしないこと。
- ブランチ名は `feature-(ページ名)-(自分の名前)` にすること。
- プルリクエストを出すときは、必ずメンバーに一声かけること。
- プルリクエストの本文にも、変更内容についてのコメントを書くこと。
